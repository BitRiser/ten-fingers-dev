# Десять пальцев · Dev Edition

Тренажёр слепой печати для программистов. Русский и английский языки, пошаговые уроки, адаптивная практика, индивидуальный план и 40 упражнений с кодом. Виртуальная клавиатура повторяет MacBook Air M1 ANSI.

## Запуск

Приложение не требует установки зависимостей или сборки. Нужен современный браузер и любой сервер статических файлов.

```sh
cd dist
python3 -m http.server 8765 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8765/`.

## Проверки

Из корня проекта, с Node.js 20 или новее:

```sh
node tests/practice-progress.mjs
node tests/code-content.mjs
node tests/onboarding-plan.mjs
```

Проверки покрывают условия открытия букв, защиту от случайных нажатий, сохранение и перенос прогресса, английские профили, упражнения с кодом, обучение и персональные маршруты.

## Структура

- `dist/` — готовый сайт и все исходные модули, HTML, CSS и SVG.
- `tests/` — проверки учебной логики.
- `.openai/hosting.json` — конфигурация существующего сайта в Sites.

Прогресс занятий хранится в браузере. Его резервную копию можно скачать в настройках данных сайта.

## Сохранение изменений

Рабочая ветка: `codex/typing-app`. Дальнейшие изменения сохраняем отдельными коммитами и отправляем в эту ветку или в новую ветку с префиксом `codex/`.

```sh
git status
git add dist tests README.md AGENTS.md .gitignore
git commit -m "Describe the completed change"
git push
```

Не отправляем изменения в `main` или `master`.
