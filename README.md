# Десять пальцев · Dev Edition

Тренажёр скорости печати для программистов. Русский и английский языки, практика букв и текста, пошаговые уроки и 750 вариантов упражнений с кодом. Виртуальная клавиатура повторяет MacBook Air M1 ANSI.

## Запуск

Скачай **весь ZIP ветки `codex/typing-app`** через GitHub → Code → Download ZIP и распакуй архив. Все 31 аудиофайл уже входят в `dist/audio`; интернет после скачивания не нужен.

Нужен Python 3. На Mac открой `start.command`, на Windows — `start.bat`. Откроется браузер, окно сервера оставь открытым. Если система не запускает файл двойным щелчком, используй терминал в папке проекта:

```sh
python3 start.py
```

На Windows: `py -3 start.py`. Сервер доступен только на этом компьютере по `http://127.0.0.1:8765/`. Другой порт: `python3 start.py --port 8766`. Проверка комплекта без запуска: `python3 start.py --check`.

**Звук изначально выключен на каждом новом устройстве.** В практике нажми «Включить звук» под текстом либо «Настройки → Звук → Обычный → Послушать». Проверь ползунок громкости, громкость системы и отключение звука у вкладки. Для мемных реплик выбери режим «Особый». Не открывай `dist/index.html` напрямую: режим `file://` блокирует модули и загрузку аудио. Если проверка сообщает о недостающих файлах, скачай и распакуй полный ZIP заново.

Для любого другого статического сервера корень сайта — `dist/`, `.mjs` должен передаваться как `text/javascript`. Статическая часть работает без сборки. Регистрация и синхронизация требуют серверных функций Vercel и базы Neon PostgreSQL.

## Проверки

Из корня проекта, с Node.js 20 или новее:

```sh
node tests/practice-progress.mjs
node tests/code-content.mjs
node tests/onboarding.mjs
node tests/typing-audio.mjs
node tests/hand-model.mjs
node tests/lesson-map.mjs
node tests/test-material.mjs
node tests/material-variety.mjs
node tests/skipped-input.mjs
node tests/session-preview.mjs
node tests/lesson-difficulty.mjs
node tests/security.mjs
```

Проверки покрывают условия открытия букв, защиту от случайных нажатий, сохранение и перенос прогресса, английские профили, упражнения с кодом, знакомство с интерфейсом и сохранение пользовательских данных.

В «Настройки → Звук» доступны MacBook, Linear Red, Tactile Brown и Clicky Blue, обычный звук и дополнительный режим. Red, Brown и Blue используют записи Cherry MX из MechVibes (MIT), по четыре разных нажатия и отдельные записи пробела, Enter и Backspace. MacBook — тихая обработка записи Red, а не запись конкретной модели ноутбука; раскладка MacBook Air M1 ANSI сохраняется. Звук изначально выключен. Громкость и выбор сохраняются вместе с настройками, а короткие мемные аудиосэмплы входят в сайт. Их источники записаны в `dist/audio/sources.json`. Кнопка под виртуальной клавиатурой открывает эти же настройки. В дополнительном режиме нажатия — нейтральный короткий вокальный фрагмент на 100 мс с мягким затуханием, а девять полных финальных реплик случайно чередуются без повторов подряд. Финал звучит один раз на упражнение; пробное упражнение обучения исключено.




В тесте по словам и по времени можно отдельно включить цифры и знаки или выбрать «Только слова». Настройки сохраняются. Числа считаются отдельными словами, поэтому длина задания не меняется; цитаты остаются исходным текстом автора. Результат показывает состав задания, а личные рекорды разделены по выбранной сложности.

Компактная статистика показывает среднюю скорость с понятными единицами, точность с учётом исправленных опечаток, активное время и открытые буквы. Рекорды, клавиши и история раскрываются по желанию.

## Структура

- `dist/` — готовый сайт и все исходные модули, HTML, CSS и SVG.
- `tests/` — проверки учебной логики.
- `.openai/hosting.json` — конфигурация существующего сайта в Sites.

Без входа прогресс хранится в браузере. После входа сохраняется в аккаунте; резервная копия доступна в настройках.

## Сохранение изменений

Рабочая ветка: `codex/typing-app`. Дальнейшие изменения сохраняем отдельными коммитами и отправляем в эту ветку или в новую ветку с префиксом `codex/`.

```sh
git status
git add dist tests README.md AGENTS.md .gitignore start.py start.command start.bat
git commit -m "Describe the completed change"
git push
```

Не отправляем изменения в `main` или `master`.

Главная помещается в экран ПК или ноутбука: три входа в практику и ссылки на уроки и тест. Индивидуальный план удалён. При начале набора рабочая область автоматически закрепляется в окне, клавиатура подбирает размер под оставшуюся высоту. Текущая строка держится на одной высоте, текст поднимается при переходе к следующей. Esc и кнопка паузы возвращают обычный вид. В компактной статистике показаны четыре метрики, график и последние пять занятий; рекорды, буквы и полная история раскрываются отдельно.


Записи механических клавиш: [MechVibes](https://github.com/hainguyents13/mechvibes/tree/main/src/audio), лицензия сохранена в `dist/audio/mechvibes-LICENSE.txt`. Источники и границы всех клипов — в `dist/audio/sources.json`.


В библиотеке 82 разных текста RU/EN о работе, разработке и повседневных ситуациях. Выбор не зависит от числа завершённых попыток: показанный вариант расходуется сразу, порядок хранится отдельно в `ten-fingers-material-v1`. Корпус перемешивается без повторов до конца колоды, включая перезагрузку и выход из задания. У кода чередуются разные алгоритмы, а имена меняются согласованно во всех местах.

Руки — схематичная подсказка положения, с человеческими пропорциями пальцев и ладони, видимыми сгибами и ногтями. Небольшой сдвиг кисти сопровождает смену ряда; дальние клавиши вызывают больший перенос всей руки. Три фаланги сохраняют длину, а промежуточные положения ограничены, чтобы при быстром наборе пальцы не складывались назад. Shift использует мизинец противоположной руки, пробел — суставной большой палец. Ориентиры: [OSHA: свободные кисти и нейтральное запястье](https://www.osha.gov/etools/computer-workstations/components/wrist-palm-support), [Typing.com: согнутые пальцы над клавишами](https://www.typing.com/blog/typing-posture/).

Практика букв содержит 16 слов длиной 2–8 букв: настоящие связующие слова и учебные слова, разные начала и двойные буквы. Счётчик показывает конечный объём. Код: короткий 8–12, средний 13–18, длинный 19–25 слов; 750 отдельных вариантов сохраняются. Перед первым набором каждого задания текст показывается в центре на две секунды. Предпросмотр не входит во время набора и отменяется по Esc, смене страницы или потере фокуса. После паузы повторный предпросмотр не нужен.

Каждая пропущенная буква при переходе по пробелу учитывается как ошибка ввода и ошибка соответствующей клавиши, включая полностью пропущенное слово. Повторное возвращение к тому же пропуску не дублирует штраф; исправление не стирает историю ошибки. Истечение таймера не штрафует за ещё не набранный остаток текста. Неверно нажатая клавиша вспыхивает красным на 260 мс; рука не совершает нажатие на неверную клавишу.

Первые уроки: две домашние клавиши, восемь одиночных нажатий, 65% точности без проверки скорости; следующие шаги — десять пар. Один успешный результат открывает обычный шаг. Сложность материала, точность и скорость увеличиваются постепенно до 90% и 320 CPM. Новые группы клавиш сначала снова изучаются без ограничения скорости; контрольный последний этап поздних глав требует двух успешных попыток подряд. Пройденные этапы сохраняются.

В v5.8 шкала букв остаётся красной до 60% цели включительно и плавно зеленеет от 60% до 100%. Самая слабая доступная буква определяется по средней скорости последних пяти измеренных попыток; неизвестные буквы не сравниваются с измеренными. Карта уроков объединена в один маршрут с мягкими изгибами между этапами и главами. Код — 75 разных структур (по пять на язык и объём), каждая с десятью наборами имён.

## v5.9: уроки и главная

Каждый запуск урока меняет порядок материала и немного меняет объём (разброс до трёх слов). «Повторить» сохраняет предыдущий материал. Требования первого блока: 60, 75, 90, 110, 130 CPM; далее — постепенный рост до 320 CPM. На главной показана анимация рук: сначала ошибки и медленный набор, затем ровный ритм и ускорение. Системная настройка уменьшения движения отключает анимации.

Проверка безопасности и её границы описаны в SECURITY.md. Вход, серверная база пользователей и перенос на другой хостинг пока не настроены; текущий сайт опубликован через Sites, прогресс остаётся в браузере.

Во время набора прогресс-бар и текущий CPM остаются чёткими в фокусе. Скорость появляется после первой секунды фактического набора. В звуках дополнительный режим скрыт до ввода кода 2884; название исходного режима в интерфейсе не показывается. Код — клиентское ограничение интерфейса, не система безопасности и не пароль аккаунта.


В целевой практике выбранной буквы она присутствует в каждом из 16 слов (2–8 букв). Кнопка нового текста сохраняет выбранную букву, «Повторить» сохраняет сам текст.

Основной адрес Vercel: https://tenfast-progg.vercel.app/ . Предыдущий адрес сохраняется как дополнительный; локальный прогресс привязан к адресу, для переноса используется экспорт/импорт резервной копии в настройках.

## Аккаунты на Vercel

Только логин и пароль (10–128 символов), без email. Восстановления пароля через почту нет. При регистрации можно перенести гостевой прогресс. Каждый аккаунт имеет отдельную локальную копию; выход возвращает гостевой профиль. Изменения сохраняются автоматически, а «Сохранить сейчас» позволяет повторить синхронизацию.

Подключить Neon PostgreSQL Free к production-проекту Vercel и добавить серверную переменную `DATABASE_URL` (либо `POSTGRES_URL`), затем выполнить новое развёртывание. Секрет не добавлять в Git или клиентский JavaScript. Таблицы создаются сервером при первом обращении: `typing_users`, `typing_sessions`, `typing_progress`, `typing_rate_limits`. Пока база не подключена, форма честно сообщает об этом и не принимает регистрации.

Vercel устанавливает закреплённый драйвер через `npm ci`; локальные проверки API запускаются командой `node tests/account.mjs` без базы и пакета. Статический запуск через Python обеспечивает гостевую практику, без серверных аккаунтов.

Анимация на главной ускоряется от 35 до 400 CPM, затем ещё 12 секунд продолжает печатать на 400 CPM. Фрагменты меняются без соседних повторений.

## Пробный рейтинг

В статистике — топ-10 отдельно для RU и EN. Участие добровольное: «Участвовать в рейтинге» публикует логин и лучший подходящий результат; «Убрать меня» скрывает их. Учитываются тесты на 60 секунд, только слова, точность и финальная точность от 95%, без пауз и подсказок. Кнопка теста автоматически выставляет нужные параметры. Результаты берутся из сохранённого прогресса аккаунта, записи обновляются при синхронизации. Без входа доступен просмотр.

Это beta: исходные результаты клиентские, импорт прогресса доступен, полноценного античита нет. Публичный API не выдаёт UUID, тексты, историю, хеши или данные сессий. Таблица `typing_rank_scores` и флаг участия создаются автоматически сервером.


Система образцов удалена. Следующая буква открывается после достижения полной цели скорости каждой доступной буквой в последней качественной попытке с точностью от 85%. Количество повторений не проверяется. Практика и результат показывают следующую букву и раскрываемый список причин: нет измерения, недостаточная скорость, точность или качество задания. История и уже открытые буквы сохранены.

Автоматическая практика выбирает самую слабую измеренную букву среди включённых. Она встречается в каждом слове. Пока замеров нет, тренируется новая буква. Начальные слова меняются между заданиями; шаблон «он/она/они» больше не используется как постоянное вступление.

Открытие букв больше не требует скорости ни для буквы, ни для задания: только завершённая качественная попытка, минимум два верных ввода каждой доступной буквы и точность 85%. Скорость и шкала остаются ориентиром для выбора слабой буквы. Цвет правильного нажатия одинаковый зелёный для всех свитчей; ошибки остаются красными.
