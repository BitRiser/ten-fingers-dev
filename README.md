# Десять пальцев · Dev Edition

Тренажёр слепой печати для программистов. Русский и английский языки, пошаговые уроки, адаптивная практика, индивидуальный план и 40 упражнений с кодом. Виртуальная клавиатура повторяет MacBook Air M1 ANSI.

## Запуск

Приложение не требует установки зависимостей или сборки. Нужен современный браузер и любой сервер статических файлов.

```sh
cd dist
python3 -m http.server 8765 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8765/`.

## Проверки

Из корня проекта, с Node.js 20 или новее:

```sh
node tests/practice-progress.mjs
node tests/code-content.mjs
node tests/onboarding-plan.mjs
node tests/typing-audio.mjs
node tests/hand-model.mjs
node tests/lesson-map.mjs
```

Проверки покрывают условия открытия букв, защиту от случайных нажатий, сохранение и перенос прогресса, английские профили, упражнения с кодом, обучение и персональные маршруты.

В «Настройки → Звук» доступны MacBook, Linear Red, Tactile Brown и Clicky Blue, обычный звук и режим гачимучи. У каждого профиля свой синтезированный звук нажатия; раскладка MacBook Air M1 ANSI сохраняется. Звук изначально выключен. Громкость и выбор сохраняются вместе с настройками, а короткие мемные аудиосэмплы входят в сайт. Их источники записаны в `dist/audio/sources.json`. Кнопка под виртуальной клавиатурой открывает эти же настройки. В режиме гачимучи нажатия — нейтральный короткий вокальный фрагмент на 100 мс с мягким затуханием, а три полные финальные реплики случайно чередуются без повторов подряд. Финал звучит один раз на упражнение; пробное упражнение обучения исключено.

На главной видны назначение тренажёра и три пути: уроки с нуля, практика букв и код. В уроках сначала показаны ближайший шаг и две главы. Все 11 глав соединены последовательно; дальний и пройденный путь раскрываются по желанию. Общая шкала курса сохраняется. Для открытия новой буквы нужны три качественных образца (порог 70% цели, точность 95%) и полная цель скорости. История и уже открытые буквы сохраняются. Для кода доступны 1, 3 или 6 полных авторских примеров в задании; они предназначены для набора и не исполняются. Режим фокуса мягко размывает окружение, сохраняя текст, руки, клавиатуру и подпись нужного пальца чёткими. Кнопка «Пауза / выйти · Esc» закреплена в углу экрана и остаётся доступной при прокрутке. Пауза и завершение возвращают интерфейс.


Руки отображаются как объёмная SVG-подсказка: фиксированные фаланги, палец заранее указывает на следующую клавишу, независимые движения по фактическим нажатиям, касание и возврат к подсказке, Shift другой рукой и пробел большим пальцем. Форма ногтей учитывает наклон последней фаланги. Принципы исходной позы сверены с [Typing.com](https://www.typing.com/blog/typing-posture/).

## Структура

- `dist/` — готовый сайт и все исходные модули, HTML, CSS и SVG.
- `tests/` — проверки учебной логики.
- `.openai/hosting.json` — конфигурация существующего сайта в Sites.

Прогресс занятий хранится в браузере. Его резервную копию можно скачать в настройках данных сайта.

## Сохранение изменений

Рабочая ветка: `codex/typing-app`. Дальнейшие изменения сохраняем отдельными коммитами и отправляем в эту ветку или в новую ветку с префиксом `codex/`.

```sh
git status
git add dist tests README.md AGENTS.md .gitignore
git commit -m "Describe the completed change"
git push
```

Не отправляем изменения в `main` или `master`.
