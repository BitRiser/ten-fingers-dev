# Работа с проектом

Основная рабочая копия тренажёра находится в этом репозитории. Исходники готового сайта — в `dist/`, проверки — в `tests/`. Статическая часть не требует сборки; серверные функции Vercel используют закреплённый Neon-драйвер через npm ci.

Пользователь попросил дальнейшую работу вести с сохранениями в GitHub. После завершения согласованного изменения сделай понятный коммит и отправь текущую рабочую ветку в `origin`. Используй `codex/typing-app` или новую ветку с префиксом `codex/`. Не отправляй изменения в `main` или `master` и не перезаписывай историю.

Перед изменениями проверь `git status` и сохрани изменения пользователя. Для учебной логики запускай соответствующие проверки из `tests/`; для изменений интерфейса проверяй сайт в браузере на ПК и ноутбуке.

Сохраняй клавиатуру MacBook Air M1 ANSI, отдельные профили RU / EN, неподвижный текст при пробеле внутри строки, текущую строку на постоянной высоте, размытие вне набора и результат до явного действия пользователя. Случайные нажатия и пропущенные слова не должны открывать буквы. Пробное упражнение обучения не попадает в статистику.

Пользователь выбрал Vercel: публикация через push ветки codex/typing-app в подключённый проект ten-fingers-dev. Не изменяй прежний Sites-проект без отдельного запроса.

Основной упор — скорость печати программиста. Главная должна помещаться в один экран ПК/ноутбука; основные виды практики — буквы, связный текст и код. Индивидуальный план удалён по просьбе пользователя. Статистика компактная, расширенные данные раскрываются по желанию.

Система образцов удалена. Следующая буква открывается по последней качественной попытке каждой доступной буквы: полная цель скорости и точность 85%. Причины показывает practiceUnlockStatus. По просьбе пользователя уроки начинаются с 75% и 60 CPM, затем требования постепенно растут до 90% и 320 CPM; материал случайный, длина меняется в пределах трёх слов; используется единый `lessonThreshold` для логики и интерфейса. Не ослабляй защиту от пропусков и случайного ввода. Код содержит 5 разных фрагментов на каждый из 3 объёмов (8–12, 13–18, 19–25 слов) и 10 наборов имён для каждого языка. Новые упражнения должны меняться даже без завершения предыдущего, а явный повтор сохраняет материал. Палец не должен растягиваться или складываться назад; ладонь участвует в перемещении между рядами.
